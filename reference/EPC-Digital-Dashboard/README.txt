EPC DIGITAL TRANSFORMATION COMMAND CENTRE  -  LOCAL PACKAGE
============================================================

HOW TO USE
1. Unzip this folder to D:\EPC-Digital-Dashboard   (any folder works).
2. Double-click  Open-Dashboard.bat   (or open index.html in Chrome / Edge).
3. Bookmark the page in your browser for quick access.

NO INTERNET OR INSTALLATION NEEDED
Everything (PDF engine, fonts) is inside the folder. Keep the folders
"lib" and "fonts" next to index.html - do not move index.html alone.

WHERE YOUR DATA IS STORED
Data you enter is saved inside your browser on this computer.
 - Always open the dashboard in the SAME browser and from the SAME folder
   path (e.g. always D:\EPC-Digital-Dashboard\index.html). A different
   browser or a different folder path shows an empty dashboard.
 - Clearing browser data / site data deletes your entries.
 - BACK UP REGULARLY: click "Export" (top right) to save a .json backup
   file, e.g. to D:\EPC-Digital-Dashboard\Backups. Use "Import" to restore
   it, or to move your data to another PC / browser.

WEEKLY PDF REPORT
Open the "Weekly Report" tab, fill in the optional notes, choose the week
and click "Download PDF report". The PDF is saved through your browser's
download folder (or a Save dialog, depending on browser settings).

PHOTOS / FILES
Photos are compressed before saving. Attached files must be under 1.8 MB
each. Large photo collections can fill browser storage - Export a backup
if you add many.

PRESENT MODE
Click "Present" for a full-screen auto-rotating showcase (Esc to exit).

LOADING THE AUG-OCT 2026 STATUS DATA
The package opens pre-filled with the Aug-Oct 2026 status (10 initiatives,
38 activities). If your browser already holds older data, click "Import" and
choose EPC-Dashboard-Data-Aug-Oct-2026.json (included in this folder).

UPDATING TO A NEW VERSION WITHOUT LOSING YOUR DATA
Your data is NOT stored in these files - it lives in your browser. So:
 1. FIRST click "Export" in the old dashboard and keep that .json backup.
 2. Unzip the new package INTO THE SAME FOLDER (e.g. D:\EPC-Digital-Dashboard)
    and choose "Replace the files in the destination".
 3. Open it in the SAME browser from the SAME path. Your data appears
    automatically, with the new features.
 4. If it ever looks empty, click "Import" and pick your backup .json.
Never open the dashboard from a different folder path or a different browser
for day-to-day use - that is the only way to "lose" data (it is still safe in
the original browser, and in your Export backup).

NEW IN THIS VERSION (v2)
 - Edit an activity: open it, click "Edit" (title, owner, initiative, hours).
 - Remove photos (x on each photo), slides, attached files, activities,
   team members and initiatives, with a confirmation prompt.

THEME (v3)
 Use the theme button at the top right to switch Auto (follows your computer) / Light / Dark. Your choice is remembered.

MULTIPLE RESOURCES PER ACTIVITY (v4)
 Tick one or more people when assigning or editing an activity. The estimated hours are shared equally between them in the Resources tab.

RICH-TEXT DETAILED ACTIONS (v5)
 Open an activity or an initiative and use "Detailed action" > "+ Add" / "Edit". Write as much as you need with bold, italic,
 headings, bullets, numbering, colours, highlight, tables and links. You can paste from Word / email (formatting is kept, unsafe
 content is removed). Images are not stored inside notes - attach them as photos/files instead.

EXECUTIVE PRESENTATION MODE (v7)
 Click "Slides" (top right) for a 9-slide executive review: Cover, Executive summary (KPIs), Portfolio health,
 Roadmap, Client commitments, Momentum, Risks & decisions, Next 90 days & capacity, Close.
 Tap any KPI, initiative card, roadmap row, constraint or look-ahead column to DRILL DOWN into the detail
 (overview, actions, updates & constraints, notes, photos). Esc closes the detail first, then the deck.
 Keys: Right/Space = next, Left = back, F = full screen, Home/End. On a tablet: swipe.
 "Present as slides" (Initiatives tab) and "Present this initiative" open the same deck; the category filter is respected.

EDITING & NATIVE FILE OPENING (v8)
 - Progress updates, achievements and value entries each have an edit (pencil) and delete (x) button on the initiative page.
   Value realised is always the total of the value entries.
 - Attach ANY file type to an action (PowerPoint, Excel, Word, PDF, images...). Large files are kept in the browser's file
   storage (up to 200 MB each). Open the action, select the file and click "Open in native app": it is saved with its original
   name and opens in PowerPoint / Excel / Word / Acrobat (in Chrome/Edge click the downloaded file in the download bar).
   "New tab" shows PDFs and images in a browser tab.
 - Export now bundles attached files into the .json backup (the file can be large). Import restores them.

30-DAY ENTRY LOCK (v9)
 Progress updates, achievements and value entries can be edited or deleted only for 30 days after they were entered.
 After that they show a lock and become read-only; new entries can always be added. Entries that already existed when
 you installed v9 count from the day you first opened v9. The lock is enforced inside the dashboard; it is not a
 server-side audit control (anyone with access to the browser data or a backup file could still change it).
